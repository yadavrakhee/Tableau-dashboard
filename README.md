# Tableau-dashboard

## Electric Vehicle Data Analysis dashboard 

## Project Overview
This Tableau dashboard provides a comprehensive analysis of electric vehicle (EV) adoption and distribution across different dimensions. The dashboard visualizes key metrics related to both Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs) in the United States.

# Dashboard Components

## Key Metrics

 - Total Vehicles: 28,502 vehicles tracked in the dataset
 - Avg Electric Range: Information on the average electric range of vehicles
 - Total BEV Vehicles: Count and distribution of battery electric vehicles
 - Total PHEV Vehicles: Count and distribution of plug-in hybrid electric vehicles

## Geographic Analysis

  - Total Vehicles By State: Interactive map showing EV distribution across US states
  - California (CA) appears to have the highest adoption rate
  - States are labeled with their respective vehicle counts



# Temporal Analysis

 - Total Vehicles By Model Year: Line chart showing EV adoption trends from 2012 to 2023
 - Notable peak around 2021-2022 with approximately 37,079 vehicles
 - Significant growth periods in 2018 and 2021



# Manufacturer Analysis

  ## Top 14 Total Vehicles by Make: Bar chart showing distribution by manufacturer

   - Toyota leads with 5,016 vehicles (15.34%)
   - Chevrolet follows with 4,879 vehicles (14.92%)
   - BMW ranks third with 4,635 vehicles (14.18%)



# Model Breakdown

   - Total Vehicles By Model: Table showing distribution by specific models

   - Notable models include BMW 330E, FIAT 500



# Filtering Options

  - EV Type: Filter for BEV, PHEV, or both
  - State: Filter by US states
  - Additional filters available in the dashboard interface

# Technical Information

   - Built using Tableau Desktop Public Edition
   - Contains multiple interactive worksheets:

 * Total Vehicles
 * Avg Electric Range
 * Total BEV Vehicles
 * Total Vehicles By Model
 * Total Vehicles By State
 * Top 10 Total Vehicles By Make
 * Total Vehicles by CAFV Eligibility



# Usage
 ## This dashboard can be used to:

  - Track EV adoption trends over time
  - Compare market share between manufacturers
  - Analyze geographic distribution of EVs
  - Understand the split between BEV and PHEV adoption
  - Identify popular EV models

# Data Sources
The dashboard appears to be using a comprehensive dataset of US electric vehicles, likely including registration data from DMVs or similar sources. The data covers the period from approximately 2012 to 2023.
